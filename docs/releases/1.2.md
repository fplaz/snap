# Snap 1.2

- Hold Space after selecting a screenshot area to temporarily use the Select tool. Release it to restore the previous tool.
- Press Tab to cycle through annotation tools. Normal text input remains available while editing an annotation.
- A five-page tutorial introduces capture, moving and resizing the area, Google sign-in and uploads, annotation tools, and keyboard shortcuts.
- The tutorial appears automatically once per macOS user. Skip or close it at any time, and reopen it from the menu bar’s “Tutorial…” option.

Quit Snap before replacing it in Applications. This release uses the existing self-signed distribution identity and remains unnotarized.
