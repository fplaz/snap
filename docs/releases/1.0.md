# Snap 1.0

- Menu-bar screenshots with Command + Shift + 7.
- Rectangle selection, drawing, shapes, text, undo/redo, PNG copy and save.
- Drag the selection border to move the capture area, annotations, and toolbar together.
- Optional Google Drive upload, public viewing links, and screenshot history.
- Updated app icon and a universal Intel / Apple Silicon download for macOS 14+.

This release is self-signed and unnotarized. Users need to approve first launch through macOS Privacy & Security. Updates are installed by quitting Snap and replacing the app in Applications. Screen Recording or Keychain permission may need to be approved again; stability across updates remains subject to verification on another Mac.
